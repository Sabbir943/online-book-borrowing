# 📚 Library Management System

A seamless and modern web application designed to digitize the traditional library experience. Users can explore a vast collection of books, filter by categories, and borrow titles digitally. The platform focuses on performance, security, and user-friendly experience using modern web technologies.

---

## 🚀 Features

- 🔐 Secure Authentication with BetterAuth
- 📚 Browse and Explore Books
- 🏷️ Category-Based Filtering
- 🔎 Search Functionality
- 📖 Borrow Books Digitally
- 👤 User Dashboard
- ⚡ Fast and Optimized Performance
- 📱 Fully Responsive Design
- 🌙 Modern UI with Tailwind CSS + DaisyUI/HeroUI

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- React.js
- Tailwind CSS
- DaisyUI
- HeroUI

### Backend & Database
- BetterAuth
- MongoDB
